## 🎯 Cómo Usar Este Repositorio

### Para Diseñadores
1. Navega a la carpeta del proyecto deseado
2. Descarga los archivos DOCX o PNG
3. Consulta el README para detalles específicos
4. Usa el mockup como referencia en tus diseños

### Para Desarrolladores
1. Lee el resumen técnico (Summary.md)
2. Revisa las especificaciones de implementación
3. Consulta la paleta de colores y componentes
4. Implementa siguiendo las guías del mockup

### Para Product Managers
1. Consulta el README para entender el contexto
2. Revisa las métricas y KPIs incluidos
3. Usa el Summary.md para presentaciones ejecutivas
4. Descarga el DOCX para compartir con stakeholders

## 📝 Convenciones de Nomenclatura

### Ramas
- `feature/[nombre-proyecto]-mockup` - Nuevos mockups
- `feature/[nombre-proyecto]-react` - Implementaciones React
- `feature/[nombre-proyecto]-[especificacion]` - Variantes específicas

### Archivos
- `[Nombre_Proyecto]_Mockup.docx` - Documento principal
- `[Nombre_Proyecto]_Summary.md` - Resumen ejecutivo
- `README.md` - Documentación de navegación
- `images/` - Directorio de imágenes

---

## 🤝 Contribuir

Para añadir un nuevo mockup:

1. Crea una nueva rama: `feature/[nombre-proyecto]-mockup-[año]`
2. Crea la estructura de carpetas: `mockups/[nombre-proyecto]/`
3. Añade los archivos requeridos:
   - Mockup principal (DOCX o PNG)
   - README.md con descripción
   - Summary.md con especificaciones técnicas
   - Imágenes en subcarpeta `images/`
4. Actualiza este índice principal
5. Commit y push a la rama
