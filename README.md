## 📋 Proceso de Generación de Mockups

1. **Input:** URL de Figma o archivo PNG
2. **Extracción:** Descarga de imagen desde Figma o carga manual
3. **Generación:** Creación automática de PowerPoint
4. **Documentación:** Archivo markdown con detalles del mockup
5. **Versionado:** Creación de rama específica en Git
6. **Output:** Archivo descargable desde el chat
